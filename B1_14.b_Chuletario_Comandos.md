**Máquinas:** Servidor = B1-UbuntuServer (consola) · Cliente = B1-Win11 (PowerShell como administrador) · Anfitrión = tu Windows físico (PowerShell normal).

| Nº | Dónde | Comando | Qué hace |
| :--- | :--- | :--- | :--- |
| 1 | Servidor | `hostname` | Muestra el nombre del servidor. Debe ser el de B1.14a. |
| 2 | Servidor | `ip -br a` | Lista las tarjetas y sus IP. La de LAB_RED debe tener 10.10.10.10/24. |
| 3 | Servidor | `sudo ss -ltnp` | Lista los puertos abiertos. Tiene que salir el 22. |
| 4 | Anfitrión | `ssh -p 2214 TU_USUARIO@127.0.0.1` | Entra en el servidor por SSH. |
| 5 | Servidor | `exit` | Sale de la sesión SSH. |
| 6 | Cliente | `Get-NetAdapter` | Lista las tarjetas de red con su MAC. |
| 7 | Cliente | `ipconfig` | Muestra la IP de cada tarjeta. La de LAB_RED tiene 169.254.x.x. |
| 8 | Cliente | `New-NetIPAddress -InterfaceAlias "Ethernet 2" -IPAddress 10.10.10.20 -PrefixLength 24` | Pone la IP fija 10.10.10.20/24, sin puerta de enlace. |
| 9 | Cliente | `ping 10.10.10.10` | Prueba la conexión con el servidor. Responde. |
| 10 | Servidor | `ping -c 4 10.10.10.20` | Prueba la conexión con el cliente. Falla hasta crear la regla 11. |
| 11 | Cliente | `New-NetFirewallRule -DisplayName "LAB - Ping entrante (ICMPv4)" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -Action Allow` | Deja entrar solo el ping en el firewall de Windows. |
| 12 | Servidor | `sudo reboot` | Reinicia el servidor. Al volver: 2, 9, 10 y 4-5. |

> [!warning] Ojo
> Usa el nombre real de tu tarjeta («Ethernet 2» es el habitual). Nunca apagues el firewall: solo se abre el ping. `Tab` completa nombres y rutas; la flecha ↑ repite el último comando.
