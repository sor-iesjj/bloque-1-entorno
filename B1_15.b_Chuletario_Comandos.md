**Máquinas:** Servidor = B1-WinServer (PowerShell) · Cliente = B1-UbuntuDesktop-HV (Terminal: Ctrl + Alt + T) · Anfitrión = tu Windows físico (PowerShell con permisos de Hyper-V).

| Nº | Dónde | Comando | Qué hace |
| :--- | :--- | :--- | :--- |
| 1 | Servidor | `ipconfig` | Muestra las IP. La tarjeta de LAB_RED debe tener 10.10.10.10. |
| 2 | Anfitrión | `Set-VMFirmware -VMName "B1-UbuntuDesktop-HV" -SecureBootTemplate MicrosoftUEFICertificateAuthority` | Cambia la plantilla de arranque seguro para que arranque Ubuntu. Con la VM apagada. |
| 3 | Cliente | `ip -br a` | Lista las tarjetas y sus IP. La de LAB_RED no tiene IPv4. |
| 4 | Cliente | `ip link` | Muestra la MAC de cada tarjeta. |
| 5 | Anfitrión | `Get-VMNetworkAdapter -VMName "B1-UbuntuDesktop-HV" \| Select-Object Name, SwitchName, MacAddress` | Muestra la MAC de cada tarjeta del cliente, vista desde Hyper-V. |
| 6 | Cliente | `nmcli connection show` | Lista los perfiles de red con su UUID. |
| 7 | Cliente | `sudo nmcli connection modify uuid UUID_REAL ipv4.method manual ipv4.addresses 10.10.10.20/24 ipv4.gateway "" ipv4.never-default yes connection.autoconnect yes` | Pone la IP fija 10.10.10.20/24 en el perfil existente, sin puerta de enlace, y lo activa al arrancar. |
| 8 | Cliente | `sudo nmcli connection up uuid UUID_REAL` | Reactiva el perfil para aplicar los cambios. |
| 9 | Cliente | `nmcli device status` | Muestra el estado de cada tarjeta en NetworkManager. LAB_RED, conectada. |
| 10 | Cliente | `ping -c 4 10.10.10.10` | Prueba la conexión con el servidor. |
| 11 | Servidor | `ping 10.10.10.20` | Prueba la conexión con el cliente. Funciona a la primera. |
| 12 | Cliente | `sudo reboot` | Reinicia el cliente. Al volver: 9 y 3. |

> [!warning] Ojo
> En Hyper-V las tarjetas de Ubuntu suelen llamarse eth0 y eth1: usa la tuya. Cambia UUID_REAL por el UUID de tu perfil de LAB_RED (comando 6). La barra | se escribe con AltGr + 1. `Tab` completa nombres y rutas; la flecha ↑ repite el último comando.
