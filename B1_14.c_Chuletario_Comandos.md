**Máquinas:** Servidor = B1-UbuntuServer (consola) · Cliente = B1-UbuntuDesktop (Terminal: Ctrl + Alt + T).

| Nº | Dónde | Comando | Qué hace |
| :--- | :--- | :--- | :--- |
| 1 | Servidor | `ip -br a` | Lista las tarjetas y sus IP. LAB_RED debe estar UP con 10.10.10.10/24. |
| 2 | Cliente | `ip -br a` | Lista las tarjetas y sus IP. La de LAB_RED no tiene IPv4. |
| 3 | Cliente | `ip link` | Muestra la MAC de cada tarjeta. |
| 4 | Cliente | `nmcli device status` | Muestra el estado de cada tarjeta en NetworkManager. |
| 5 | Cliente | `nmcli connection show` | Lista los perfiles de red con su UUID. |
| 6 | Cliente | `sudo nmcli connection modify uuid UUID_REAL ipv4.method manual ipv4.addresses 10.10.10.20/24 ipv4.gateway "" ipv4.never-default yes connection.autoconnect yes` | Pone la IP fija 10.10.10.20/24 en el perfil existente, sin puerta de enlace, y lo activa al arrancar. |
| 7 | Cliente | `sudo nmcli connection up uuid UUID_REAL` | Reactiva el perfil para aplicar los cambios. |
| 8 | Cliente | `ping -c 4 10.10.10.10` | Prueba la conexión con el servidor. |
| 9 | Servidor | `ping -c 4 10.10.10.20` | Prueba la conexión con el cliente. Funciona sin tocar cortafuegos. |
| 10 | Cliente | `sudo reboot` | Reinicia el cliente. Al volver: 4 y 2. |

> [!warning] Ojo
> Cambia UUID_REAL por el UUID de tu perfil de LAB_RED (sale en el comando 5). La IP también se puede poner con ratón: Configuración → Red → engranaje → IPv4. `Tab` completa nombres y rutas; la flecha ↑ repite el último comando.
